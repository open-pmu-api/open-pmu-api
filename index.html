API publique de données hippiques

Les résultats PMU, prêts à être interrogés.

Open PMU API permet aux développeurs de consulter les résultats des courses hippiques françaises et leurs détails par date, hippodrome ou prix.

Documentation

Interroger les résultats des courses

Envoyez une requête GET avec un seul filtre. L’endpoint disponible est /api/arrivees. Les résultats sont renvoyés au format JSON.

Paramètres de requête disponibles
Paramètre Description Exemple
date Date de la course (MM/JJ/AAAA) 09/29/2026
hippo Nom de l’hippodrome Chantilly
prix Nom du prix PRIX DE LA CHAMBRE DU DUC

Utilisez un seul filtre par requête. La recherche par prix ou hippodrome peut renvoyer plusieurs courses.

Exemples de requêtes

GET "https://open-pmu-api.vercel.app/api/arrivees?date=09%2F29%2F2026"
GET "https://open-pmu-api.vercel.app/api/arrivees?hippo=Chantilly"
GET "https://open-pmu-api.vercel.app/api/arrivees?prix=PRIX%20DE%20LA%20CHAMBRE%20DU%20DUC"

Format de la réponse

error indique si la recherche a échoué, total correspond au nombre de courses renvoyées, et message contient les courses ou un message explicatif. Chaque course peut inclure son arrivée et les détails disponibles sur les chevaux.

    "total": 1,
    "params": {
        "date": "09/29/2026"
    },
    "message": [

            "distance": 1900,

Les champs présentés sont indicatifs et varient selon la course. En cas d’échec, error: true est accompagné d’un message explicatif.

Les données

Courses et partants dans une même réponse

L’API interroge une base de données de courses hippiques. Selon la course et les informations disponibles, les résultats peuvent inclure la date, l’hippodrome, le prix, la discipline, la distance, les partants et non-partants, l’arrivée officielle et les détails des chevaux : noms, jockeys, entraîneurs, cotes, gains et musique.

Disponibilité et utilisation responsable

Cet endpoint public est accessible sans clé API pour les requêtes simples. Aucune limite de débit, garantie de disponibilité ou pagination n’est publiée ; la disponibilité et la taille des réponses peuvent varier. Pour un usage régulier ou en volume, demandez l’accès à la base plutôt que de répéter des requêtes larges.
